Dieser Ordner ist absichtlich flach aufgebaut, damit alle Dateien auf dem iPad in einem Schritt ausgewählt und zu GitHub hochgeladen werden können.

WICHTIG:
- Nicht die ZIP-Datei allein ins Repository legen.
- ZIP zuerst in der Dateien-App entpacken.
- Danach ALLE Dateien in diesem Ordner markieren und auf GitHub über Add file > Upload files hochladen.
- index.html muss direkt im Hauptverzeichnis des Repositorys liegen.
